# Atividade Bootstrap - Estúdio Maré

Página de um estúdio de fotografia fictício, feita para a disciplina do professor Elton (UCSal).

- `bootstrap/` - solução principal, com Bootstrap 5.3 via CDN
- `tailwind/` - mesma página feita com Tailwind CSS via CDN (desafio extra)

Componentes: navbar, carrossel, cards, tabela, formulário e modal.

## Como rodar

Abrir o `index.html` de qualquer uma das pastas no navegador, ou no Codespaces:

```bash
python3 -m http.server 8000
```

e abrir a porta 8000 que o Codespaces encaminha.
